# Заявки, кабинет УК и «Мой дом»

- Единая сущность заявки: APPLICATION (Запрос), QUESTION, EMERGENCY, PROBLEM, COMPLAINT. Старые записи и ссылки сохраняются.
- Одна форма с выбором типа, одинаковая навигация и терминология.
- Кабинет УК /admin: все заявки, фильтры организации/типа/статуса, экстренные активные выше остальных. /admin/requests/:id: детали, фото, история, допустимые переходы с комментарием.
- API /api/admin/requests, /api/admin/requests/:id (+history/photo), PATCH /status. Без авторизации только для демо; отдельные admin API без привязки к тестовому жителю.
- Статусы: CREATED/SENT → ACCEPTED или REJECTED; ACCEPTED → IN_PROGRESS или REJECTED; IN_PROGRESS → RESOLVED или REJECTED. Завершённые записи не меняются. Комментарий обязателен при отказе.
- /house и GET /api/house: тестовый дом, площади, этажность, подъезды, квартиры, год, УК, ответственный, контакты. Данные из PostgreSQL.
- Версионированная миграция существующей базы без сброса заявок и фото; комментарий и автор изменения в истории.
- Проверки: Go tests/vet, build, REST (новые типы, миграция, переходы, история), Playwright (житель → УК → житель, дом, фильтры, мобильный экран).
