# Дополнительные доверенные сертификаты MAX

Если MAX API требует отсутствующий в системном хранилище корневой сертификат,
получите актуальный PEM из доверенного официального источника и положите его
в `certs/max-ca.pem`. В `.env` укажите `MAX_CA_CERT_FILE=/app/certs/max-ca.pem`.
Compose монтирует эту папку в backend только для чтения. Файлы PEM/CRT не коммитятся.
Сертификат добавляется к системным корням только для MAX-клиента.
TLS-проверка никогда не отключается. Не помещайте сюда приватные ключи.
